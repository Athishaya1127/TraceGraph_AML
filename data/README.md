# Dataset

TraceGraph was evaluated using the PublicAMLSimData / AMLSim dataset.

The raw dataset is intentionally not included in this repository.

## Dataset used in the experiment

- Transactions: 17,144
- Accounts: 100
- Alerts: 18
- Fraud-labelled transactions: 18
- Normal transactions: 17,126
- Fraud rate: approximately 0.105%

The complete data preparation and validation process is available in the TraceGraph notebook.
